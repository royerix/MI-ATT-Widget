# MI AT&T Widget

Widget para Scriptable que consulta el consumo de datos de una cuenta AT&T México mediante el portal Mi AT&T.

## Versión
**V16.3** — versión probada por el autor.

## Instalación
1. Descarga el archivo instalador `.scriptable` de la sección Releases.
2. En iPhone, abre el archivo y compártelo con Scriptable para importarlo.
3. Ejecuta el script desde Scriptable y captura tus propias credenciales de Mi AT&T cuando las solicite.
4. Agrega un widget de Scriptable a la pantalla de inicio y selecciona `MI AT&T V16.3`.

## Actualización
El widget muestra datos almacenados localmente. Al tocarlo se ejecuta Scriptable para consultar el portal y actualizar la caché. La actualización programada de widgets de iOS no garantiza una consulta automática al portal.

## Privacidad
Las credenciales se solicitan al usuario y se almacenan localmente mediante Keychain de Scriptable. No publiques contraseñas, tokens, datos de cuenta ni archivos de caché.

## Aviso
Proyecto comunitario no afiliado, patrocinado ni respaldado por AT&T. El funcionamiento depende de la disponibilidad y cambios del portal Mi AT&T.
